# VIETON — Website Specification & Creative Direction

> **Project:** Vieton Corporate / Growth & Commerce Website  
> **Stack:** Next.js + TypeScript + CSS  
> **Visual Direction:** White × Blue × Global  
> **Experience:** Premium, international, interactive, animation-driven  
> **Primary Market:** Southeast Asia

---

## 1. Project Overview

Vieton is a company operating across:

- Performance Marketing / Advertising
- Product sourcing and importing
- E-commerce
- Product testing and scaling
- Market expansion across Southeast Asia

The website must communicate that **Vieton is more than an advertising agency**.

The core positioning is:

> **Vieton builds and scales businesses across Southeast Asia.**

The website should make visitors understand three things within the first few seconds:

1. **Who is Vieton?**
2. **What does Vieton do?**
3. **Where does Vieton operate?**

The visual identity should communicate:

- Global ambition
- Technology
- Commerce
- Growth
- Reliability
- Speed
- Cross-border connectivity

# 3. Visual Direction

## Concept

# WHITE × BLUE × GLOBAL

The website should use a predominantly white canvas with blue accents and subtle global/network visual language.

- Clean
- Premium

- Digital

## Usage

White should dominate the interface.

Recommended approximate balance:

```text

Deep Blue        1–5%
```

Blue should be used as:

- Interactive accent
- Network lines
- Buttons
- Highlights
- Active states
- Data visualization
- Important typography
- Animation elements

Do not make every section blue.

# 5. Typography

Recommended typefaces:

- Geist
- Inter
- Manrope

Typography should be large and editorial.

Example hero:

```text

MARKET.
SCALE.
```

The headline can occupy a significant portion of the viewport.

Use:

- Large display typography
- Strong hierarchy
- Short sentences
- Large whitespace
- Tight headlines
- Comfortable body text

Avoid long corporate paragraphs above the fold.

# 6. Overall User Experience

The website should feel like a **creative interactive corporate website**, not a static company profile.

The experience should use:

- Scroll storytelling
- Text reveals
- Parallax
- Horizontal scrolling
- Pinned sections
- Interactive maps
- Network animations
- Hover interactions
- Count-up statistics
- Page transitions
- Cursor interactions
- Optional 3D/WebGL elements

However:

> Animation must support the story, not distract from it.

The website must remain:

- Fast
- Responsive

# 26. Page Transitions

Navigation between pages should not feel like a hard refresh.

Possible transition:

1. White page
2. Blue line expands
3. New page content reveals
4. Line contracts/disappears

Target:

```text
300ms–800ms
```

Avoid long transitions that make navigation feel slow.

---

# 27. Animation Principles

Every animation should have a purpose.

Use animation to:

- Guide attention
- Explain business processes
- Show market connections
- Create hierarchy
- Make the brand memorable
- Communicate growth

Avoid:

- Excessive bouncing
- Random particles
- Constant movement
- Slow page transitions
- Animation on every element
- Heavy 3D without a purpose

---

# 28. Recommended Animation Stack

## Primary

### GSAP

Use for:

- ScrollTrigger
- Scroll storytelling
- Pinning
- Horizontal scroll
- Parallax
- Timelines
- Complex sequences
- Count-up
- SVG path animation

## Secondary

### Motion / Framer Motion

Use for:

- Component transitions
- Menu
- Hover interactions
- Modal
- Simple reveals
- Layout animations

Do not duplicate the same animation system unnecessarily.

## Optional

### Three.js / React Three Fiber

Use only when the project needs:

- 3D globe
- 3D product
- WebGL network
- Interactive 3D visualization

Do not add Three.js just because the site needs animation.

# 31. Server vs Client Components

Keep static content as Server Components where possible.

Use `"use client"` only for interactive components such as:

- Navbar menu
- GSAP animation components
- Mouse interactions
- Interactive map
- 3D scenes
- Hover state components
- Contact form with client-side interaction

Do not turn the entire application into Client Components.

---

# 32. Responsive Design

Desktop should receive the full creative experience.

Mobile should preserve the story without forcing desktop animations onto a small screen.

## Desktop

Use:

- Horizontal scrolling
- Large typography
- Mouse interaction
- Full network visualization
- Pinning
- Rich parallax

## Tablet

Reduce:

- Particle density
- Motion complexity
- Large offsets

## Mobile

Prefer:

- Vertical storytelling
- Simplified network
- Tap interaction
- Reduced parallax
- Smaller typography
- Fewer simultaneous animated elements

---

# 33. Accessibility

Respect:

```css
@media (prefers-reduced-motion: reduce) {
  /* Reduce or disable non-essential animations */
}
```

Users who prefer reduced motion should still receive the complete content and navigation experience.

Do not make critical information depend only on animation.

---

# 34. Performance

Because the website is animation-heavy, performance is a major requirement.

## Rules

- Optimize images
- Use Next.js Image
- Lazy-load heavy media
- Avoid huge background videos
- Avoid unnecessary WebGL
- Animate transform/opacity where possible
- Avoid excessive DOM nodes
- Avoid expensive scroll handlers
- Use GSAP ScrollTrigger appropriately
- Disable complex effects on low-power/mobile devices where necessary

Target:

- Smooth scrolling
- Fast initial load
- Minimal layout shift
- Good Core Web Vitals

# 43. Non-Negotiable Design Principles

1. White must remain the dominant background.
2. Blue is the primary visual accent.
3. Global connectivity must be visible in the visual language.
4. Animation should tell a story.
5. Typography should be a major visual element.
6. Avoid generic corporate templates.
7. Avoid fake statistics.
8. Do not overuse 3D.
9. Keep the site fast despite the animation.
10. The mobile experience must remain excellent.
11. The About section must appear early on the homepage.
12. The site should communicate Vieton's complete business chain:
   **Product → Marketing → Commerce → Market → Scale.**
